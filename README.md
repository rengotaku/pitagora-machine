# pitagora-machine

ブラウザで動く、眺め続けるためのピタゴラ装置（ルーブ・ゴールドバーグ・マシン）。

複数のボールが坂を転がり、落ち、シーソーを傾け、発射され、ドミノを倒し、
エレベーターで上へ戻される — その連鎖が止まらずに回り続ける装置です。
ゲームではなく kinetic art / スクリーンセーバーとして眺めることを目的にしています。

## 動かす

```bash
make install   # 依存インストール (npm ci)
make run       # http://localhost:5173
```

ブラウザで開くだけで動きます。バックエンドはありません。

画面右上の歯車ボタンから、重力・ボール数・速度・デバッグ表示・リセットを操作できます。
通常時はボタン以外の UI を出しません。

## 仕掛け

```
投入口 → 坂1 → 分岐ゲート → 振り子 → ドミノ → シーソー
      → 発射装置 → 坂2 → 回転ホイール → バウンド床 → エレベーター → 投入口へ戻る
```

分岐は片側に偏り続けないよう補正が入り、ボールはサイズ・色・反発にばらつきがあります。
同時に 5 個前後が流れ、互いに衝突して軌道が変わります。

## 技術

| 項目 | 内容 |
|---|---|
| 物理エンジン | [Matter.js](https://brm.io/matter-js/) |
| 描画 | Canvas 2D（Matter.js の Render は使わず自前描画） |
| ビルド | Vite + TypeScript |
| テスト | Vitest（カバレッジ対象は `src/lib/**` の純粋ロジック） |

## 座標系

装置は `1600 x 900` の論理座標で組み立て、表示時にアスペクト比を保ったまま
ウィンドウへ収めます（`src/lib/viewport.ts`）。ウィンドウサイズによって
装置のレイアウトが変わらないため、「どの画面でも詰まらない」ことを検証できます。
